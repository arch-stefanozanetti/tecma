# Security runbook — Followup 3.0

## Scopo

Runbook minimo per eseguire i controlli sicurezza sul perimetro greenfield.

## Comandi

- `pnpm run security:hardening`
- `pnpm run test:hardening`

## Note

- I report vengono prodotti in `security-reports/`.
- Il codice legacy o POC non rientra nello scope operativo di questo runbook.
